# Prop Material Creator

[Русский](README.md) | [English](README.en.md)

Строит Karma MaterialX-материалы для **одиночного FBX-пропа** в Houdini Solaris
и назначает их на геометрию — одной кнопкой. Соседний инструмент к Character
Material Tool, живёт на той же полке **CGA Tools**.

## Что делает

Берёт плоскую папку `textures` одного пропа, где каждый файл назван
`<материал>_<канал>` (`body_dif.png`, `button_bump.png`, `chip_dif.png`), и:

1. Группирует текстуры по префиксу материала.
2. Строит по одному сабнету `mtlxstandard_surface` на каждый материал внутри
   `materiallibrary` LOP.
3. Назначает каждый материал на соответствующий `GeomSubset` (или меш) пропа.

Область по задумке: **один проп = один FBX + его собственная папка текстур.**
Всё, что лежит в папке, принадлежит этому пропу.

## Установка

1. Скачай последнюю версию из [последнего релиза](https://github.com/himakarov/prop-material-creator/releases/latest).
2. Найди папку пользовательских настроек Houdini и папку `packages` внутри неё
   (создай `packages`, если её ещё нет):

   - Windows: `C:/Users/<name>/Documents/houdini22.0/packages/`
   - macOS: `~/Library/Preferences/houdini/22.0/packages/`
   - Linux: `~/houdini22.0/packages/` (подставь свою версию)

3. Распакуй zip прямо в папку `packages`, чтобы получилось:

   ```
   houdini22.0/
   └── packages/
       ├── prop_material_creator.json
       └── PropMaterialCreator/
           ├── VERSION
           ├── python/
           ├── config/
           └── scripts/
   ```

   Переименовывать ничего не нужно — архив уже разложен правильно.

4. Перезапусти Houdini. На полке **CGA Tools** появится кнопка **Prop Mat**.

## Использование

1. Импортируй проп в `/stage` (SOP Import / SOP Create).
2. Выдели эту ноду в сети `/stage`.
3. Нажми **Prop Mat** на полке CGA Tools.
4. Выбери геометрию пропа в дереве, укажи папку текстур, нажми **Build**.

## Карта каналов

Все имена живут в `config/channel_map.json`. Правится вручную — добавить алиас
суффикса или сменить colorspace можно без изменений кода.

У каждого канала:

| ключ         | смысл                                                            |
|--------------|-----------------------------------------------------------------|
| `aliases`    | суффиксы имён файлов, ведущие в этот канал (без учёта регистра)  |
| `colorspace` | `srgb` или `raw`                                                 |
| `mtlx_input` | вход `mtlxstandard_surface`, куда идёт текстура                  |
| `signature`  | сигнатура mtlximage (`color3` / `float` / `vector3`)            |
| `via`        | опциональный узел-помощник: `mtlxnormalmap` или `mtlxbump`       |

По умолчанию покрыты: `dif/diffuse/albedo`, `refl/rough`, `metal`, `spec`,
`normal`, `bump/height`, `opacity`, `emission`, `ao`.

## Пресеты материалов

Слот геометрии без текстур, чьё имя совпадает с пресетом (`glass`, `metall`,
`white_plastic`, ...), получает материал по умолчанию из блока
`material_presets` в `channel_map.json`. Текстуры всегда важнее пресетов.

## Матчинг

Материал → геометрия матчатся по порядку: точное имя (без учёта регистра) →
нормализованный нечёткий (разделители убраны) → вхождение префикса.
Несматченная геометрия и неиспользованные материалы попадают в отчёт после
каждой сборки.

## Обновление

Кнопка **Check for updates** тянет последнюю версию с GitHub. Если есть более
новая — она скачивается и перезаписывает локальные файлы (твой отредактированный
`channel_map.json` при этом сохраняется). После обновления перезапусти Houdini.
Кнопка **Changelog** показывает, что изменилось.
